Recommendation and implementation

I recommend B · Ground contact. Its ring shows contact with terrain, while the central crosshair stays readable at a shallow angle. A is quieter; C is more conspicuous but may look like a placed object.

Use one terrain query for both preview and placement. MapLibre already performs the intersection; a small adapter must distinguish a real hit from missing terrain or a fallback coordinate. This needs real-browser verification before implementation.

These are schematic, generated terrain views. The marker sizes and terrain ring are visual proposals, not a tested rendering implementation. The raised locator uses a fixed screen-space stem, not an altitude measurement. No map interaction or point placement runs on this page.
